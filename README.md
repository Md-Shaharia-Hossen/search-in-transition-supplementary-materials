# search-in-transition-supplementary-materials
# Supplementary Materials

## Search in Transition: A Mixed-Methods Study of LLMs and Search Engines in English Test Preparation

This repository contains the supplementary materials supporting the manuscript:

> **Search in Transition: A Mixed-Methods Study of LLMs and Search Engines in English Test Preparation**

These materials are provided to facilitate transparency, reproducibility, and peer review.

---

## Repository Contents

### data/

Contains the anonymized datasets used in the study.

- survey_data_anonymized.xlsx
- survey_data.csv
- processed_data.xlsx
- variable_description.xlsx

The survey dataset has been fully anonymized. No personally identifiable information is included.

---

### questionnaire/

Contains all data collection instruments.

- Survey questionnaire
- Interview protocol
- Interview tasks
- Task evaluation rubric

These materials were used during the data collection phase of the study.

---

### analysis/

Contains the analysis resources used in this work.

- Statistical analysis scripts
- Data preprocessing code
- Analysis notebook (if applicable)

These files reproduce the quantitative analyses reported in the manuscript.

---

## Data Availability

The anonymized survey dataset, survey questionnaire, interview protocol, task evaluation rubric, variable descriptions, and statistical analysis resources are provided in this repository.

Raw interview transcripts are not publicly shared to protect participant confidentiality and comply with the approved ethical protocol. They may be made available to the journal editor upon reasonable request and subject to institutional ethical approval.

---

## Ethics

This study received approval from the Institutional Review Board (IRB), BRAC University, Bangladesh.

All participants provided informed consent prior to participation.
